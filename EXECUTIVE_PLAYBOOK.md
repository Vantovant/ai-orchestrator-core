# VantoOS Executive Playbook — Beta User Guide

Welcome to VantoOS, your executive operating system built for South African entrepreneurs. This playbook walks you through getting started and experiencing the "10-minute win."

---

## 🔐 Data Sovereignty First

VantoOS is built on a principle of absolute data sovereignty. To guarantee zero-context bleed between users:

- **Your AI keys stay yours.** To guarantee data sovereignty, you can connect your personal OpenAI or Gemini key in Settings → AI Keys.
- **No shared AI.** Your data never passes through shared inference pipelines.
- **PII protection.** Sensitive information (SA IDs, emails, phone numbers) is automatically scrubbed before any AI processing. You'll see a 🔒 toast confirming this.
- **Verification badges.** When AI output isn't grounded in your uploaded documents, you'll see a ⚠ Needs verification badge.

---

## 🚀 Onboarding: Your 10-Minute Win

### Step 1: Connect Your AI Key (2 minutes)

1. Go to **Settings → AI Keys**
2. Toggle "Use my own API keys" ON
3. Paste your OpenAI key (starts with `sk-...`) or Gemini key (starts with `AI...`)
4. Click **Test** to verify — you'll see a ✓ Connected badge
5. Click **Save AI Settings**

**Where to get keys:**
- OpenAI: https://platform.openai.com/api-keys → Create new secret key
- Gemini: https://aistudio.google.com/apikey → Create API key

### Step 2: Run the Demo Tender (5 minutes)

1. Go to **Projects → + New Project**
2. Click **Demo Tender Wizard**
3. Choose "SAWS" or "GTA" demo
4. Watch VantoOS automatically generate:
   - Business case
   - Compliance checklist
   - Readiness scores
   - Task breakdown

### Step 3: Review Your Results (3 minutes)

1. Check the **Readiness Score** on your project
2. Browse generated tasks (sorted by priority)
3. Note the verification badges — review flagged items

**Congratulations!** You've experienced VantoOS's core automation in under 10 minutes.

## 🌐 Chrome Extension: VantoOS Companion

### Setup

1. Install the VantoOS Companion extension
2. Go to **Settings → Chrome Extension** in VantoOS
3. Click **Generate Pairing Code**
4. Enter the 6-character code in the extension's Settings tab
5. Add domains you work with (e.g., `docs.google.com`, `gov.za`)
6. Grant browser permissions when prompted

### Capture Modes

**Quick Capture** — Save any web page's URL, title, and highlighted text to a project inbox. No AI needed.

**Smart Capture (AI)** — AI analyzes the full page structure, extracts a summary and actionable tasks. Requires your AI key.

> To guarantee zero-context bleed and uphold data sovereignty, Phase 1 isolates secure web capture. Native OAuth Gmail read-only sync ships as a separate secured module in Phase 2.

### Floating Button

On allowed domains, you'll see a small "V" button on the right side of the page. Click it to instantly open the VantoOS side panel — no need to find the extension icon.

### Apply Tasks

After Smart Capture extracts tasks:
1. Review the checklist
2. Uncheck any you don't want
3. Click **Apply Selected Tasks**
4. See the receipt: "X created, Y merged"
5. Click **View in VantoOS →** to see them in your project
