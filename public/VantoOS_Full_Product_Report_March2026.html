📋 1. Executive Summary

VantoOS is an AI-powered executive operating system designed for South African leaders managing complex, multi-stakeholder professional lives. Unlike generic productivity tools, VantoOS acts as a living secretary — proactively surfacing the right information, preparing for meetings, managing financial intelligence, and providing PhD-level strategic advice for every project.

The platform consolidates 12 functional modules, 32+ database tables, 17 serverless edge functions, and a multi-model AI architecture into a single keyboard-first interface with full mobile responsiveness.

🧠 4. AI Partner Memory System

Each project maintains a persistent Partner Memory — a structured card that grounds all AI interactions with consistent context across sessions:

  • North Star — The project's ultimate goal
  • Target Customer — Who the project serves
  • Business Model — How it makes money
  • Stage — idea / mvp / beta / live / scaling
  • Primary Constraint — Current bottleneck
  • Weekly Focus — This week's priority
  • Key Assumptions & Risks — JSON arrays for tracking
  • Auto-update toggle — AI can propose memory updates (default OFF)

Memory is injected into every AI Partner call, ensuring the AI never "forgets" strategic context. Updates require explicit user confirmation (diff preview).

⚠️ 10. AI Non-Negotiable Rules

  • Snapshot cap ≤ 3,000 characters for AI context windows
  • POPIA redaction: SA IDs, bank numbers, addresses stripped before any AI call
  • Confirm-before-create: All AI-suggested actions require explicit user approval
  • No hallucinated funding: Specific programs only from verified funding_cache with source URLs
  • No secrets in logs or client-side code
  • AI Partner Memory updates require diff preview + user confirmation
  • All suggested tasks use the existing task schema — no custom fields
